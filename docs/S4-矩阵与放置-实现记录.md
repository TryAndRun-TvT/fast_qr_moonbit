## 2. 关键实现决策与语义

### 2.1 之字形放置（`place_on_matrix_data`，对照 `placement.rs:36`）
- **右列序列** = `(0..6) ∪ (7..size)` 逆序后**隔项取一**（Rust `.rev().step_by(2)` 等价物）：
  从最右列起、每两列一组（右列 x + 左列 x-1），跳过第 6 列（timing 列）。
- **行向交替**：每对列内 y 方向 `rev` 取反（首对自底行往顶、次对自顶往底……），即之字形。
- **只写 Data**：逐格判定 `is_data_byte`，命中才写入下一位并推进 `idx`；功能图案一律跳过不覆写。
- **位序大端**：`structure[idx/8]` 的第 `(7 - idx % 8)` 位（MSB first），与参考一致。
- 总消费位数 = 矩阵 Data 模块数 = `max_bytes(version) × 8`（如 V1 = 26×8 = 208）。

### 2.2 总装 `create_fixed_qr`（对照 `placement.rs::place_on_matrix` 固定 mask 分支）
顺序不可颠倒（时序铁律 §五.7）：
1. `create_matrix(version)`：功能图案 + Format 占位；
2. `place_on_matrix_data`：放置**未掩码**原始码字位；
3. `create_matrix_format_info`：以真实 15 位 Format 覆写（含固定 mask 的异或后位序）；
4. `apply_mask`：一次固定 mask，**只翻 Data 类**，Format/功能图案不动；
5. 返回 packed 字节矩阵（`明暗 | 类型<<1`，D3 介质）。

### 2.3 M1 编排 `QRCode::build_fixed`（对照 `placement.rs::create_matrix`）
```
select_capacity(input, mode, ecl, version)        // mode/ecl/version 解析（None 自动）
  → @data_encoding.encode                        // 位流缓冲（前 data_codewords 字节为数据码字）
  → @reedsolomon.structure                       // 5430 缓冲，前 max_bytes(version) 字节为交织码字
  → @matrix.create_fixed_qr                      // 放置 + Format + 固定 mask
  → 逐格包装回公共 Module → QRCode（元数据为解析值）
```
`mask` 为**必填**：M1 只做指定固定 mask 的「首码」闭环；8 轮择优评分（S5/B10）不在此列。

## 3. 验证与对齐

### 3.1 快照逐位对齐（黑盒 `m1_snapshot_test.mbt`）
以 Rust 侧 `fast_qr v0.14.0` 新增 `examples/snapshot_gen.rs` 生成固定
mode=Byte / ecl / version / mask 的完整矩阵（每格 = `Module.0` = `明暗|类型<<1`，与 MoonBit 公共
`Module.byte()` 同构），转 hex 后嵌入 MoonBit 黑盒测试比对。
覆盖 **V1 / V5 / V7 / V10 × L / M / Q / H × mask 0 / 1 / 2 / 3 / 5 / 7**，含：
- V7+/V10 版本信息区（V7+ 右下/左上两块）；
- mask 5（`(x*y)%2+(x*y)%3`）与 mask 7（`((x+y)%2+(x*y)%3)%2`）类非平凡网格；
- Format 真实覆写与固定 mask 的交织正确性。
**8 条全部逐格 0 差异。**

### 3.2 白盒护栏（`placement_wbtest.mbt`）
- 全 1 位喂满后所有 Data 置暗、功能图案不改写、V1 恰 208 个 Data；
- 逆序读回与喂入位流逐位一致（等价参考遍历序）；
- `create_fixed_qr` 掩码后非 Data 类型号不漂移。
