## 2. 实测解决的「待实测决策」（S1 方案 §5）

### 2.1 固定大小矩阵 → 用 `Array[Module]` 预分配（方案 §5.1）
MoonBit 固定容量容器 `[Module; 31329]` 在类型面不易表达，实测采用
`QRCode.data : Array[Module]`，经 `Array::make(QR_MAX_MODULES, light)` 一次性预分配
到 31329（`QR_MAX_WIDTH=177`、`QR_MAX_MODULES=31329`）。语义对齐 Rust「固定容量、按行
存储」：所有 QRCode 恒为 31329 槽，有效区 `size*size`，越界槽不参与渲染。
（正是方案 §5.1 给出的 Array 兜底；若后续测量到必要可再评估固定容器。）

### 2.2 枚举原始判别值（方案 §5.2）→ 用「枚举 + 序号映射」方案
MoonBit 枚举不支持 Rust 式显式判别值；采用方案 §5.2 的备选：枚举变体顺序 + `to_int()`
序号映射函数，`from_int()` 供回读。序号与 Rust 判别值一致：
`ECL` L/M/Q/H=0..3、`Version` V01-V40=0..39、`Mode` 0..2、`Mask` 0..7。

### 2.3 Module 归属 → 采纳 **D1**（方案 §4）
`Module`/`ModuleType` 上移 `lib/module.mbt` 作公共呈现类型，与 Rust crate 根导出对齐；
`QRCode.data` 用公共 `Module`。内部掩码/放置等字节位运算待 S4+ 在 `internal/matrix`
独立实现（不反向依赖 lib）。**`moon info` 实测：lib 公共面不含 internal 类型**（§5 验收项）。

### 2.4 KEEP_LAST 位宽 → 32 位 Int（方案 §5.4 / roadmap §3.2）
MoonBit `Int` 为 **32 位**，故 `keep_last` 取 Rust **wasm32 分支**规模：
`keep_last[k] = (1<<k)-1`（k=0..=31，32 项）。QR 编码单次 `push_bits` 位数上界 ≪ 32
（模式 4 + 计数 ≤16 + 段 ≤10/11），安全；三后端 `wasm-gc`/`wasm`/`js` 均 32 位 Int，行为一致。

### 2.5 依赖声明 → 只在用到时声明
S1 `lib/moon.pkg` 仍为空（公共类型自成一体，无需 import internal）；`internal/bitstream`
的测试由 `moon test` 模块级发现并运行（实测确认），无 `unused_package` 告警。

## 3. 实现中拍板/偏离方案的新决策

### 3.1 公共可构造枚举需 `pub(all)`（重要发现）
MoonBit 中，`pub enum` 的**变体**在**包外不可构造**（报 `Cannot create values of the
read-only type`），只有函数可 `pub` 跨包调用。因此凡是需让调用者直接构造的公共枚举/
结构（`ECL`/`Version`/`Mode`/`Mask`/`ModuleType`/`Module`/`QRCode`）一律声明为
**`pub(all)`**；仅内部 helper 函数用 `pub`。实测：`pub(all)` 后黑盒测试与真实消费方
均可 `ECL::Q`、`Version::V01` 等构造。

### 3.2 `QRCodeError` 推迟到 S3/B8（偏离方案 §1 属于 S1 的条目）
MoonBit `--deny-warn` 的 `unused_constructor` 要求每个枚举变体都在**可达非测试代码**中
被构造。S1 尚无产生 `EncodedData`/`SpecifiedVersion` 的路径（需 encode 容量判定，属
S3/B8），故**推迟 `QRCodeError` 枚举定义**到 B8 与容量判定一并落地。`QRCode` 容器及
错误收敛面的设计（两类错误）已在方案文档与 `qr.mbt` 注释中固化。

### 3.3 `from_version` 推迟到 S2（CompactQR 用 `from_bits(capacity_bits)`）
`from_version` 依赖 `version.max_bytes()`（版本容量表，属 S2）。S1 以
`from_bits(capacity_bits)` 作为原始容量构造入口，编码期零扩容、按需 `push`；
S2 容量表就绪后，再补 `from_version(v)` = `from_bits(v.max_bytes()*8)`。

### 3.4 不可变式写入风格
MoonBit 值类型缺 `&mut self`，本项目结构以**不可变式**为主（如 `Module::set/toggle`、
`QRCode::set` 返回新值）。`CompactQR` 位流因写入密集采用 `mut len` 字段 + 就地改 `Array`，
对应 Rust `&mut self` 语义。

## 4. 实现文件与公开 API（`moon info` .mbti 核对）

| 文件 | 导出 |
|------|------|
| `lib/ecl.mbt` | `pub(all) enum ECL`（L/M/Q/H）+ `to_int`/`from_int`/`to_char` + `ecl_default`（Q）|
| `lib/version.mbt` | `pub(all) enum Version`（V01-V40）+ `to_int`/`from_int`/`width` |
| `lib/mode.mbt` | `pub(all) enum Mode`（Numeric/Alphanumeric/Byte）+ `to_int`/`from_int` |
| `lib/mask.mbt` | `pub(all) enum Mask`（0-7）+ `to_int`/`from_int` |
| `lib/module.mbt` | `pub(all) enum ModuleType` + `pub(all) struct Module`（byte 位打包）+ 各类型构造/读/置/翻 |
| `lib/qr.mbt` | `pub(all) struct QRCode`（data/size/元数据 Option）+ 常量 `QR_MAX_WIDTH`/`QR_MAX_MODULES` + `default`/`for_version`/`get`/`set`/`meta` |
| `lib/internal/bitstream/bitbuffer.mbt` | `CompactQR`（`len`/`data`）+ `new`/`from_bits`/`push_u8`/`push_u8_slice`/`push_bits`/`fill` |

`Version.width()` = 版本号*4+17（V01=21，V40=177），供 QRCode 构造推导边长。
