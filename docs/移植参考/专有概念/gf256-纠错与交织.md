# GF(256) 纠错与交织

> **状态**：现行　｜　日期：2026-09-14　｜　索引：[docs/README-导航与索引.md](../../../README-导航与索引.md) §7

QR 码的容错能力来自 Reed-Solomon 纠错：数据码字在伽罗瓦域 GF(256) 上除以生成多项式，余数即纠错码字；随后多块码字按规则交织，使局部污损分散到多个块中。

## 什么是 GF(256) 纠错？

GF(256) 是以 0x11D 为本原多项式的 256 元有限域，域内乘除通过查表完成：`LOG` 表把域元素映射为幂次（alpha 记法），`ANTILOG` 反向映射。fast_qr 用这两个 256 项静态表把"多项式长除法"简化为循环异或。

**关键特征**:
- 除法即纠错：对每个数据块做 `division(data_block, generator)`，取余数多项式为纠错码字
- 生成多项式按版本与纠错级别查表（`hardcode::get_polynomial`），长度即纠错码字数（最大 30）
- 块结构查 `hardcode::ecc_to_groups`：每个 (ECL, Version) 组合分为 group1 与 group2 两组，各含若干等长块

## 算法流程

`structure(data, quality, version)` 的执行顺序：

1. 取生成多项式 `error` 与块分组 `[(g1_count, g1_size), (g2_count, g2_size)]`
2. 对 group1 每块、group2 每块分别做 `division`，余数写入 `interleaved_data` 的纠错区（按"第 j 个纠错字节、第 i 块"的跨块顺序放置）
3. 数据区交织：外层循环遍历块内偏移 i（0..max(g1_size, g2_size)），内层先轮询 group1 各块的第 i 字节、再轮询 group2 各块的第 i 字节
4. 返回的数组前段是数据码字（`data_codewords(version, quality)` 个），后段是纠错码字

### division 的实现要点

```text
from_mut: [0; 255] 栈数组，数据右对齐放置
对每个非零首项: alpha = ANTILOG[首项]
  对生成多项式每项: from_mut[i+j] ^= LOG[(by[j] + alpha) % 255]
余数即 from_mut 末尾 by.len()-1 个字节
```

## 不变量

1. **栈数组上限**：`MAX_ERROR=30`、`MAX_GROUP_COUNT=81`、`MAX_DATABITS=3000`，返回数组固定 5430 字节（V40-H 的数据+纠错总码字数），任何新版本参数不得突破
2. **纠错码字布局**：交织区中纠错码字按 `start_error_idx + j * groups_count_total + i` 索引，即"逐字节跨块"，与数据区"逐块跨字节"方向相反
3. **表驱动**：所有域运算查表完成，禁止运行时计算 alpha 幂
