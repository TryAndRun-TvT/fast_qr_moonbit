## 3. 判定：是不是「虚假」？（逐条核对）

### 3.1 属实（不构成虚假）

| 声称 | 核对方法 | 结果 |
|------|---------|------|
| 「`prefer_readonly_array` lint 已启用、零命中」 | `moon.mod` 含 `warnings = "+prefer_readonly_array"`；`moon check --warn-list "+prefer_readonly_array"` | ✅ **命中 0**，属实 |
| 「已落地 P0 掩码特化 / P2 去闭包 / P2b / T-R1·T-R2·T-R4」 | 源码可查：`datamasking.mbt` 8 特化、`score.mbt` 无闭包 + 列缓冲、RS 两表 `ReadOnlyArray` | ✅ 属实 |
| 「工作矩阵介质为 `Array[Int]`」 | 全库核对：**无任何一篇**文档谎称矩阵已用 `FixedArray` | ✅ 如实记录 |

⇒ **没有编造数据、没有谎称已落地、没有把未做的写成已做。**

### 3.2 失准（易误导，客观上助长搁置）

| # | 位置 | 原文要点 | 问题 | 实际（[S9s §10](S9s-数组介质与字节加速-真实A-B实测.md) 实测） |
|:-:|------|---------|------|------------------|
| **E1** | [S9m §4](S9m-ReadOnlyArray适用性评估.md)「为什么它救不了两大瓶颈」 | 「评分是**读+算**型，**读成本 = `FixedArray`**（…仅 1.26×）。`ReadOnlyArray` …也不改变读成本」 | 把「**只读别名**（`ReadOnlyArray` 是不可写的 identity 封装）」与「**可变、少一层间接**（`FixedArray`）」**混谈**；并以「仅 1.26×」淡化。当时矩阵是 `Array[Int]`（**两层** `{buf,len}`），换 `FixedArray[Int]`（**一层**）本就降读成本 | 矩阵介质换代：V40 宿主 **−15%**、体积 **−6%** |
| **E2** | [S9n §3](S9n-优化方案复评与wasm-gc收敛审计.md) 优先级表 P3 行 | 「独立收益（V40）：**联合上限 ≈1.26×**」 | 该 1.26× 是 **P2+P3 混算**（S9n **H1 自己已认定**「不得作为 P3 独立收益」），却**仍留在「独立收益」列**；且与 S9m 的「≈0.5%」（只算 RS）**互相矛盾**——读者无所适从 | 单因子：扫描 ≈1.19×、整 build V40 ≈−15%；**两种旧口径都没覆盖矩阵介质** |

### 3.3 遗漏（真正的「早该做」）

- **O1（挂起项无主）**：S9l（09-11）已提出 P3 并写明前置 = 独立微基准；S9n（09-12）把它固化为 **H4 门槛**；
  **但 S9o/S9r 两轮均未执行该门槛**，P3 只在「下一步」被复述 ⇒ 跨 13 天无人排期。
- **O2（论证未回灌行动）**：S9m 的**容器表**已给出「`FixedArray` = 定长可写」的正确匹配，
  **建议清单却漏项**（只列只读表）⇒ 结论与行动脱节。

## 4. 根因（为什么会拖）

1. **决策缺复审触发器**：D3（09-06）选择 `Array[Int]`；09-11 出现「容器层面更优」的新证据后，
   **没有机制回头复审 D3**（决策一旦写下即视为冻结）。
2. **术语混谈**：审查结论未区分「不可变别名（`ReadOnlyArray`）」与「可变、少一层间接（`FixedArray`）」，
   导致错误推论「矩阵需要写 ⇒ 换容器无用」。
3. **门槛挂在无人区**：H4（必须先微基准）把 P3 锁住，而**微基准本身无人排期**；
   「唯一前置门槛最高 / 风险高」的标签进一步劝退。
4. **量化框架漏项**：S9m 只量化 RS（≈0.5%，且被 `pipe` 2.5% 封顶）；S9n 用混算 1.26×。
   **两者都没给「矩阵介质」单因子量级** ⇒ 它在优先级表里既不高也不低，长期悬置。

## 7. 结论

- **Q1：不存在「早已要求」**——无规范、无 lint、无编译器要求把**可变介质**写成 `FixedArray`；
  `prefer_readonly_array` 只覆盖**只读字面量**（且已零命中）；D3 是**主动**选择。
- **Q2：确实是「早就有人提出」**——S9l（09-11）已提 P3 并写明前置微基准；S9n（09-12）固化为 H4 门槛；
  **但跨两轮无人执行**（O1 无主 + O2 未回灌行动）⇒ 拖了 13 天。
- **Q3：无虚假**——逐条核对：lint/已落地声称**属实**，介质记录**如实**；但有 **2 处失准论证（E1/E2）**
  与 **2 处遗漏（O1/O2）**，它们**低估并搁置**了该杠杆。
- **一句话教训**：**「门槛」必须同时写明「谁做、何时做、做到什么算过」——否则它等价于「不做」。**
