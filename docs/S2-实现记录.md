## 2. 落地要点与决策

### 2.1 capacity：按「(mode,ecl,len) → 最小版本」存容量上限表（修正后形态）
评估记录 §3.1 修正：capacity 真正形态是 `Version::get(mode,ecl,len)` 的**分段阈值选最小版本**，
非反查容量。实现据此把源码 **480 段判断展开为 `capacity_table[mode][ecl][version]` 单版本容量
上限**，`version_for(mode_idx,ecl_idx,len)` 线性扫最小可容纳版本（len 超 V40 → -1）。
- 表值从 `src/version.rs` `Version::get` 的 `min..=max => Vxx` 上限提取（脚本）；
- `max_bytes[40]`/`information[40]`/`alignment_grid[40]`/`missing_bits[40]` 亦脚本提取；
- `data_codewords[4][40]`（含派生 `data_bits`）随 capacity 落地（评估 §3.3），供 reedsolomon。

### 2.2 hardcode：`ecc_to_groups` 解码为四元组、`get_polynomial` 用「生成多项式 + (version,ecl) 选择索引」
- `ecc_to_groups`：源码以 `u32` 位打包 `(count<<24)|(size<<16)|(count2<<8)|size2`，实现直接存解码后
  四元组 `(g1c,g1s,g2c,g2s)`，语义等价（评估 §3.4 已核实）；
- `get_polynomial(version_idx,ecl_idx)`：评估 §3.2 修正——不是按 ec_index，而是从 31 条生成多项式中按
  `(version,ecl)` 选 1 条。实现存 `generator_polys[31]`（度 = 索引）+ `generator_index[ecl][version]`
  （**由 `(max_bytes - data_codewords) / 分组总数` 求得 = 每块纠错码字数 = 度**，与源码 match 分组
  完全一致，规避了源码分组字面量的脆弱解析）；
- `format_information[4][8]`（纠错×掩码 → 15 位字）一并落地（S5 写真实 Format 用，非 S2 算法必须）。

### 2.3 reedsolomon：照抄 polynomials.rs 语义（division 右对齐 + structure 双向交织）
- `LOG`/`ANTILOG` 各 256 项脚本提取；
- `division(data, by)`：右对齐入 255 字节工作区，对非零首项查 `ANTILOG` 得指数 alpha，逐生成项
  `LOG[(by[j]+alpha)%255]` 异或；返回尾部 `by.len()-1` 余数字节（等价 Rust 返回 `[0;255]` 后取尾）；
- `structure`：g1/g2 分块 division → 纠错区 `start_error_idx + j*groups_total + i` 逐字节跨块写入，
  数据区从 `push_idx=0` 逐块跨字节前插。返回 5430 字节缓冲（对齐 Rust 固定上限）；
- 依赖方向 `reedsolomon → constants`（moon.pkg 声明 `import`，声明的 `@constants` 已全部使用）。

### 2.4 from_version 回填
`CompactQR::from_version(version_idx) = from_bits(@constants.max_bytes(version_idx) * 8)`，
等价参考 `compact.rs::from_version`（初始容量 = max_bytes×8 比特）。为让 from_bits/max_bytes 语义
一致，实现在 bitstream 侧新增对 constants 的依赖（此前 bitstream 为纯叶、无依赖）。

## 5. 偏离与说明
- **生成多项式选择用「度推导」而非源码 match 字面量分组解析**：源码 `get_polynomial` 用 `(Vxx|Vyy…,ECL)`
  多行分组，解析脆弱易错（曾误得 V40-L→度 7）。改由
  `度 = (max_bytes - data_codewords) / 分组总数` 直接推导，全 160 项为整数且与源码一致（V01-L=7、
  V40-L=30、V40-H=30 抽验吻合）。
- `ecc_to_groups` 存储解码后四元组（非 u32 原值），避免 32 位 Int 移位溢出歧义，语义不变。
- MoonBit 数组切片无内建 `sub_array`：reedsolomon 内加私有 `slice(data,from,to)` 助手。
