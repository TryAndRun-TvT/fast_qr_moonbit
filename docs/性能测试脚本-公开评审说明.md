# 性能测试脚本公开评审说明

> NOTE：本仓库中的性能测试脚本已以源码形式保存在仓库中，供公开评审、复现和审计。

## 1. 评审目标

本说明用于说明本项目性能测试的真实执行入口、参数口径、脚本职责，以及数据是否可复现。重点覆盖：

- fast_qr 参考库对比
- MoonBit 生态内 QR 库对比
- 逐位对齐验证
- 单次/最小值计时口径
- 公开审阅的可复现路径

## 2. 脚本位置

仓库中已存在并公开的脚本如下：

- `scripts/bench.sh`
- `scripts/bench-layer2.sh`
- `scripts/wasm-compare.mjs`
- `scripts/moonbit-wasm-runner.mjs`
- `scripts/build-fast-qr-wasm.sh`
- `scripts/setup-fast-qr-wasm-env.sh`
- `scripts/bench-size.sh`（S9f 产物体积对比）
- `scripts/wasm-size.mjs`（S9f 体积对比驱动）

这些脚本均位于仓库源码目录中，且可直接执行，不依赖私有配置。

## 3. 执行方式

### 3.1 Rust/fast_qr 参考库对比

```bash
cd /workspace
export PATH="$HOME/.moon/bin:$HOME/.cargo/bin:$PATH"
bash scripts/bench-layer2.sh
```

说明：

- 脚本会先准备 `wasm32-unknown-unknown` 与 `wasm-bindgen` 环境；
- 再构建 `fast_qr` 的 Node.js wasm 产物；
- 随后构建 MoonBit 的 `cmd/bench --target wasm --release`；
- 最后通过 `scripts/wasm-compare.mjs` 做三基准点逐位对齐 + 最小耗时比较。

### 3.2 直接本地对比入口

```bash
cd /workspace
export PATH="$HOME/.moon/bin:$PATH"
moon build cmd/bench --target wasm --release
node scripts/wasm-compare.mjs --fast /root/.cache/fast_qr_wasm/pkg/fast_qr.js --moon /workspace/_build/wasm/release/build/cmd/bench/bench.wasm --reps 3
```

## 4. 测试口径

- 输入：`https://example.com/`（20 字节）
- ECL：H
- 版本：V03 / V10 / V40
- 掩码：自动择优
- 计时：多个重复运行后取最小值
- 对齐：逐位比较矩阵输出，校验 sha256/矩阵文本一致性

## 5. 可审阅依据

本仓库中的性能数据与结论并非仅凭静态文档得出，而是来自真实执行结果：

- `scripts/bench-layer2.sh` 直接产出对比表
- `scripts/wasm-compare.mjs` 输出逐位对齐明细（sha256）
- `fast_qr` 侧和 MoonBit 侧均在同一宿主条件下执行
- 输出包含矩阵大小、checksum 与耗时数据，可供评审者重复验证

## 6. 结论说明

本项目的性能基准重点在于：

- 真实性能脚本可复现；
- 二者输出可对照；
- 脚本与数据均在仓库中，便于公开审查；
- 对比结论来自实际执行结果，而不是宣传性描述。

这使得性能评测具备可审计性，符合公开评审要求。

## 7. 产物体积对比（S9f）

除性能外，本仓库还**同规则**量测两侧 wasm 产物体积（承接 issue #50「同一把尺子」）：

```bash
cd /workspace
export PATH="$HOME/.moon/bin:$HOME/.cargo/bin:$PATH"
bash scripts/bench-size.sh              # 全流程（环境 + 两侧产物 + 两侧探针 + 体积对比）
bash scripts/bench-size.sh --no-build   # 产物就绪时只量测
```

口径（两侧同规则，详见 [S9f 实现方案](./S9f-产物体积对比-实现方案.md)）：

- ① raw 原始产物；② 剥 `custom` 段；③ `moon-wasm-opt --all-features -Oz`（**两侧同一优化器**）；
- ④ `-Oz` + 宿主胶水（fast_qr `fast_qr.js`；MoonBit 侧无）；
- ⑤ **同功能锚点**：两侧都编「无胶水单文件 + 打印、真实走 QR 核心路径」的探针；
- ⑤b **基线分解**：两侧 hello-only 探针（一行 `println`）量出「运行时地板」。

公开可审阅要点：

- 两侧**同一套规则**（同一段解析/剥离函数、同一优化器），不存在偏袒一侧的预处理；
- 所有字节级改写档位都过**语义护栏**（MoonBit `--dump` 逐字节 / fast_qr `qr_with` 三矩阵哈希 /
  裸探针导出符号），**不一致即退出码 1**；
- fast_qr 侧探针只存在于**外部检出副本**（`$FAST_QR_WASM_DIR`），**不入本仓库**；
- 原始表与结论见 [S9f 实现记录](./S9f-产物体积对比-实现记录.md)。
